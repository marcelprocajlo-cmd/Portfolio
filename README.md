## 🧠 How I Work as a QA Software Tester

My testing philosophy goes beyond just clicking through an app. I follow a structured approach to ensure maximum test coverage:

1. **Requirements Analysis:** I dissect user stories to find ambiguities before development even begins.
2. **Test Design:** I use boundary value analysis and equivalence partitioning to write clear, reproducible test cases in **TestLink**.
3. **Execution & UI/UX Validation:** I test across different environments using **BrowserStack** and inspect the DOM/Network logs with **DevTools** to isolate front-end issues.
4. **API & Database First:** I don’t just trust the UI. I verify backend responses via **Postman** and double-check data persistence directly in the database using **SQL**.
5. **Smart Bug Reporting:** When I find a bug, I know how to report it in **Jira** with clear steps to reproduce, actual vs. expected results, screenshots/video recordings, and relevant DevTools console logs.
