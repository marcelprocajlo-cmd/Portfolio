### 🧠 How I Work as a Software Tester

My testing philosophy goes beyond just clicking through an app — I follow a structured approach to ensure maximum test coverage:

1. **Requirements Analysis** — dissect user stories and specs to find ambiguities before development even begins
2. **AI-Assisted Test Design** — use Claude alongside boundary value analysis and equivalence partitioning to quickly draft clear, reproducible test scenarios and cases
3. **Execution & UI/UX Validation** — test across environments using BrowserStack and Test IO, inspecting DOM/network logs with DevTools to isolate front-end issues
4. **API & Database First** — verify backend responses via Postman and double-check data persistence directly in the database using SQL
5. **Smart Bug Reporting** — report in Jira with clear reproduction steps, actual vs. expected results, screenshots/recordings, and relevant console logs
6. **Implementation Support** — take part in client-side rollouts: configuration support, acceptance testing, and production verification
