--------------------------------------------------------------------------------
KROK 1: Import kolekcji
--------------------------------------------------------------------------------
1. Otwórz program Postman i w lewym górnym rogu kliknij przycisk [ Import ].
2. Wybierz zakładkę "Link", wklej udostępniony URL i kliknij [ Import ].
3. Kolekcja pojawi się w menu po lewej stronie w sekcji "Collections".

--------------------------------------------------------------------------------
KROK 2: Automatyczne uruchomienie (Collection Runner)
--------------------------------------------------------------------------------
1. Kliknij ikonę trzech kropek (...) obok nazwy zaimportowanej kolekcji.
2. Z menu wybierz opcję [ Run collection ].
3. W panelu po prawej stronie kliknij pomarańczowy przycisk [ Run [Portfolio] ].

--------------------------------------------------------------------------------
KROK 3: Wyniki testów
--------------------------------------------------------------------------------
Postman automatycznie wyśle zapytania i wyświetli raport:
* Passed (Zielony) – Testy zaliczone (poprawne kody statusów, struktura danych).
* Failed (Czerwony) – Błąd/regresja (szczegóły widoczne w logach asercji).
